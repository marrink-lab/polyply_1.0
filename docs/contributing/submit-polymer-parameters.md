# Submit Polymer Parameters

## Workflow

We accept submissions of Martini polymer parameters to be distributed via the polyply library.
Anyone can submit parameters. To do so, simply open an
[issue](https://github.com/marrink-lab/polyply_1.0/issues) and tag it with the parameter
submission flag. In the issue, briefly describe your polymer model, and whether it has been
published previously. Subsequently, we will either help you write the relevant input files or do
it for you. More information on writing input files for the library can be found in
[Writing .ff Input Files](../reference/writing-ff-input-files.md). Submissions are subject to
our quality policy. [Here](https://github.com/marrink-lab/polyply_1.0/pull/227) you can find an
example of a previous submission.

## Disclaimer

We will briefly assess the model's quality. Submitted model parameters should have been verified
either against experimental data or atomistic simulation data. We retain the right to either
request more validation or refuse distribution if the model is unverified and/or violates the
Martini model guidelines in an obvious manner. Submission of models to the library does not
grant automatic participation in any further publications relating to polyply and/or Martini
polymer development. Becoming an author in upcoming academic publications will be decided on a
case-by-case basis.
